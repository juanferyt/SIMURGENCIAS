# Incorporación de la ampliación final

Este paquete contiene únicamente archivos nuevos o modificados respecto a la revisión base a1f2c193d957c56f7d593a46b2ac6cd29f0245df del repositorio https://github.com/juanferyt/SIMURGENCIAS.

1. Conservar una copia de tu proyecto local antes de incorporar la ampliación.
2. Extraer los archivos de la carpeta `SIMURGENCIAS` sobre la raíz del repositorio. Revisar los cambios si tu copia tiene modificaciones posteriores a la revisión base.
3. Seguir `docs/AUDITORIA_FINAL.md` para ejecutar Docker y comprobar PostgreSQL, telemetría y persistencia.
4. El modo por defecto conserva el escenario original. Para el estudio final usar el comando del README y los parámetros nuevos desde Swagger.
5. Revisar personalmente código y resultados, ensayar las respuestas de la defensa.
6. Hacer commit y push de la ampliación cuando hayas verificado el proyecto. Obtener el SHA completo con `git rev-parse HEAD` para el correo de entrega.

El informe está en `docs/INFORME_FINAL.md`. El paquete incluye resultados y figuras de 870 corridas reales de preparación, no garantiza ejecución de los contenedores en tu computador. Los archivos no se han subido automáticamente a GitHub.
